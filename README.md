# SafeLens · 安全科学论文雷达

一个面向安全科学研究的文献追踪工作台。它每天检查指定期刊的官网更新，把新论文整理进一个可搜索、可筛选、可收藏、可做笔记的工作台，而不是把论文散落在邮箱或浏览器书签里。

## 在线版（多用户）

本仓库通过 GitHub Pages 托管在线版：**https://muzi828.github.io/SubjectRadar/**

- 在线版是纯静态站点（代码在 `docs/`），无需服务器，打开即用。
- **账号与数据完全在访客浏览器里**：注册/登录只是本地密码档案（SHA-256 散列存于浏览器 IndexedDB），研究偏好、作者追踪、关键词高亮、期刊显隐、主题、笔记与收藏分别保存在各自设备上，互不可见，本站也不收集任何个人信息。
- 论文底库是一个静态快照（`docs/data/snapshot.json`），由 `.github/workflows/daily-sync.yml` 每天定时运行 `tools/build_snapshot.py` 自动更新并提交；也会不定期随本地版数据手动更新。

## 本地版（单用户，功能最全）

本地版在 `app/`，功能比在线版更全（自动每日同步、被引数刷新提醒、本地 PDF 库等），适合固定一台机器使用。

## 快速开始

1. 双击 **启动工作台.bat**，或桌面上的 **安全科学论文工作台** 快捷方式；启动过程不显示命令行窗口，如果已有工作台页面会自动刷新而不是新开窗口。
2. 浏览器会自动打开： http://127.0.0.1:8765
3. 局域网内其他设备可通过 `http://<本机局域网 IP>:8765` 访问；当前默认监听 `0.0.0.0`，请只在可信网络中使用。
4. 第一次启动时，文献库已经完成建库；点击左下角的 **刷新图标** 可以检查更新、查看今日是否已同步，运行中可中断。
5. 每天 **08:00** 的自动检查已经注册为 Windows 计划任务，即使工作台没有打开也会运行。

停止工作台：双击 **停止工作台.bat**。重新打开只需再次双击 **启动工作台.bat**；如果工作台已经在运行，启动器会刷新现有页面；没有打开的页面时才启动浏览器。

## 每天 08:00 是怎么工作的

1. Windows 计划任务 SafetyScienceMonitor_Daily0800 在每天 08:00 调用 app/sync_cli.py --trigger scheduled。
2. 同步器逐本读取期刊官网 RSS、当期目录或官方 API；英文期刊用 Crossref 补齐 DOI、作者、卷期、页码，并尝试用 OpenAlex 补摘要。
3. 论文按 DOI → PII → “期刊 + 标题”指纹去重。首次建库的论文作为基线，不会被误报成“今日新增”。
4. 之后每次检查新出现的论文会标记为 NEW，并进入 **今日新增** 和 **待读**。
5. 所有数据写入本机 SQLite：data/safelens.db。工作台关闭时也会照常更新。

计划任务带 StartWhenAvailable：如果 08:00 时电脑关机或睡眠，下一次开机后会补跑。

### 重新安装 / 修改检查时间

点击左下角齿轮打开设置弹窗，在左侧选择 **检查与同步**，修改时间后点击 **保存并安装计划任务**。也可以双击 **安装每日检查.bat** 安装 08:00 任务。

检查计划任务状态：

    Get-ScheduledTask -TaskName "SafetyScienceMonitor_Daily0800"
    Get-ScheduledTaskInfo -TaskName "SafetyScienceMonitor_Daily0800"

## 工作台功能

### 原文整合与审计 Agent

论文详情中的“原文信息 · 中英文”保留官网的标题、作者、机构、基金、摘要、关键词及官网引用、在线浏览和下载入口；不自动翻译，也不把缺失字段推断成事实。点击“抓取原文并核查”可立即更新单篇论文，展开“逐字段证据与差异”可查看原文值、库中值、来源和提取位置。新值仅补齐空字段，冲突保留供核对，笔记和收藏不受影响。元数据变化后旧审计会标为需要重新核查。

审计 Agent 是基于官网证据的规则核查器，无需模型密钥。支持通用元标签、JSON-LD，以及中国安全科学学报、指挥与控制学报和中国安全生产科学技术的专用页面/API；其他站点提取能力取决于实际页面结构，受限、验证或不支持的页面会记录失败。链接核查确认提取来源，不代表已验证下载权限或文件内容。

日常同步自动核查新增论文，每刊另外补查最多 3 篇历史记录；首次建库按有限批次处理。详情提供单篇 BibTeX、RIS / EndNote、完整元数据 JSON 和双语 CSV。JSON 包含原始提取与审计证据，引用文件由本地著录数据生成，官网原始引用单独展示。

验证（2026-11-05，逐刊复核）：17 本期刊各取一篇代表论文，已逐页打开原页并保留原页、系统详情和审计截图，见 [逐刊截图对照](docs/journal-audit/index.html)。12 家英文期刊中 Springer 原页可读，其他 11 家返回错误或安全验证页面；中文指挥与控制学报本轮 403。系统自动基础检验结果为 2 篇合格、2 篇未通过、13 篇受阻，不能视为全库合格。安全与环境学报及安全与环境工程的本地 PDF 下载接口均实际返回 200，并通过 %PDF- 文件头检查。23 项自动测试及 JavaScript 语法检查通过。未全量核查历史文献库。

- **总览**：今日新增、待读、收藏、覆盖期刊；最近入库优先展示今天匹配研究偏好的论文（最多 8 篇，不足再补最新入库）并标注“关注”。点击“查看全部”进入今日新增，按关注优先排序，总数与今日新增一致。
- **今日新增**：当天首次发现的论文，自动按期刊分组生成日报。
- **待读 / 收藏 / 稍后读 / 归档**：符合真实阅读流程的状态管理。
- **论文列表**：默认检索全部字段、按“关注优先”排序，关注论文排在前面但数据仍覆盖全部论文；每篇论文在主题标签下显示可点击的原始链接，有引用数据时显示“被引 N”。
- **上下文批量栏**：“全选本页”常驻，并提供“全选全部结果”一次选中当前筛选下的所有论文；未选择论文时导出不显示，勾选后同一行显示“已选 N 篇”、清除、批量标记操作和导出。论文卡片右上角保留收藏、稍后读、已读和打开原文的快捷图标。
- **论文详情抽屉**：摘要默认全文展开（可手动收起）、作者、卷期、DOI、原文链接、引用格式（一键复制）、在线预览、PDF 下载、主题标签、自定义标签、阅读笔记。卡片底部同时提供“原文链接”和可用的“PDF 下载”。
- **检索与筛选分区**：列表页上方用两个小标题分组：“检索”行默认选择“全部字段”，也可切换为关注点/标题/作者/摘要/DOI/期刊；“筛选”行放期刊、关键词、时间、排序和“重置”，排序默认“关注优先”。在总览页按 Ctrl K 会跳转到全部论文并聚焦。
- **期刊监控**：来源状态、今日新增、待读数、上次检查、官网链接、RSS 编辑、单刊同步。
- **日报**：仅有“今日新增”和“我的关注”两个标签，按今日汇总；每条带收藏、稍后读快捷图标，支持复制与下载。
- **主题切换**：左下角月亮/太阳图标可在浅色与深色主题间切换，选择会保存在本机。
- **设置中心**：点击左下角齿轮打开设置弹窗，左侧为分类、右侧为对应视图；包含“检查与同步、关注关键词、研究偏好、期刊管理、数据与导出、同步记录、关于”。期刊的添加、编辑、启停都在“期刊管理”中完成。
- **研究偏好**：可多选大模型、数据驱动、智能体、算法、机器学习等领域，也可追加自定义关注词；今日简报中的“我的关注”标签只汇总匹配这些偏好的论文。
- **导出**：CSV（Excel）、BibTeX（Zotero / EndNote）、Markdown。
- **关键词 / 主题**：自动识别事故与伤害、安全管理、安全文化、地质灾害与防灾、风险评估与管控、应急与救援、火灾与消防、职业健康、矿山安全、化工与过程安全、建筑施工安全、交通安全、安全智能化、安全人因工程等主题；中文期刊同时保留作者关键词。
- **国内 / 国际分组**：左侧期刊栏按“国内期刊”“国际期刊”两组排列，点击分组标题即可折叠/展开，状态会自动记住。
- **同步状态灯**：左下角刷新图标带状态灯；绿色表示今日已同步，橙色表示尚未同步，运行中会闪烁。
- **可中断检查**：检查运行时，点击左下角刷新图标可在弹出面板中查看进度、当前期刊，并随时点击“中断检查”，已完成条目会保存。
- **重复检查确认**：如果今日已经同步，再次点击刷新会先提示“本日已同步，是否仍要进行检查？”，可选择“取消”或“立即检查”。
- **关注关键词**：标题与摘要中的关注词会高亮，方便扫读；中文期刊的作者关键词在论文详情中展示。
- **作者追踪**（v1.1）：在设置 → 作者追踪中维护关注的作者/机构名单，命中论文自动进入左侧"作者关注"并在卡片上标注；今日简报的"我的关注"也包含作者命中。
- **被引数刷新与引用上升提醒**（v1.1）：距上次刷新超过 6 天的检查结束后，自动用 OpenAlex 批量刷新全库被引数；增量明显（≥max(3, 原值 50%)）的论文标注"引用上升"，可批量清除提醒。
- **本地 PDF 库**（v1.1）：点击"PDF 下载"成功后自动缓存到 data/pdfs/，之后离线可直接打开；卡片显示"本地PDF"徽标，设置 → 数据与导出可查看统计并清理失效记录。
- **相关论文推荐**（v1.1）：论文详情底部基于同作者、同主题、同关键词与同期刊本地计算相关论文，无需联网与模型密钥。

快捷键：Ctrl K 搜索；Esc 关闭面板；详情抽屉中用 ← / → 切换上一篇/下一篇。

## 数据源与限制

- **官网来源优先**：RSS、当期目录或官方 API 是发现“官网新发布论文”的主来源；读取失败或期刊没有官网源时才回退 Crossref。
- **Crossref**：补齐 DOI、作者、卷期、页码，并补充少量官网 RSS 尚未出现的最近记录。
- **OpenAlex**：尝试补摘要和引用数。Elsevier 的 RSS 通常不提供摘要，部分论文的摘要可能仍然为空；此时点击“打开原文”查看出版商页面。
- 所有网络请求只在本机发起，不需要账号或 API Key；数据不上传到任何第三方服务。
- 出版商的 “in press” 论文可能显示未来的卷期日期（例如 2027 年 3 月），这是期刊分配卷期的结果；工作台按“入库时间”发现新论文，不按未来出版日期判断新旧。
- 需要稳定的网络连接。若某本期刊官网临时限制访问，该期刊会显示“检查异常”，其他期刊不受影响。

## 手动命令

    # 检查全部期刊
    python app\sync_cli.py --trigger manual

    # 只检查一本期刊（slug 或 id）
    python app\sync_cli.py --journal safety-science

    # 启动服务（不自动开浏览器）
    python app\server.py --no-browser

    # 安装/修复计划任务
    powershell -ExecutionPolicy Bypass -File scripts\install_scheduler.ps1 -DailyTime "08:00"

## 常见问题

**双击后浏览器没有打开？**
手动访问 http://127.0.0.1:8765 。如果端口被占用，关闭旧的 SafeLens Server 窗口后重试。

**今日新增一直是 0？**
首次建库的论文属于基线，不计入“今日新增”。等下一次 08:00 检查后，新论文才会出现。也可以在“全部论文”查看已建库内容。

**某本期刊显示检查异常？**
打开该期刊官网/RSS 确认网络可访问；在“期刊监控”编辑该期刊的 RSS 地址，或暂时停用。同步记录会保留错误信息。

**计划任务显示 1999 年 / 返回码 267011？**
这是 Windows 计划任务“从未运行”的占位值，不是错误。安装后第一次到点运行或手动运行后会更新。

**论文没有摘要？**
RSS 元数据不一定包含摘要，Elsevier 尤其常见。系统会尝试用 Crossref / OpenAlex 补全；没有补到的论文仍可通过“打开原文”阅读。

**数据在哪里？**
data/safelens.db。备份时复制这个文件即可（建议先停止工作台）。日志在 logs/。

## 隐私

这是一个本地优先工具：服务只监听 127.0.0.1，没有云端账户、遥测或上传。论文元数据与你的阅读状态都保存在本机 SQLite 中。
